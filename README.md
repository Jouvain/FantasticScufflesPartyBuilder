# Fantastic Scuffles Party Builder

Angular roster builder scaffold using standalone components, SCSS, feature-oriented folders, and static placeholder UI.

## Commands

```bash
npm install
npm start
npm run build
```

## Structure

- `src/app/core/layouts` contains the application shell and navigation.
- `src/app/features/roster` contains the roster page, overview, constraints banner, unit cards, and editor drawer.
- `src/app/features/rules` contains the rules reference page placeholder.
- `src/app/features/import-export` contains import and export action placeholders.
- `src/app/shared/ui` contains reusable presentation components.
- `src/styles` contains global theme tokens and base styles.
